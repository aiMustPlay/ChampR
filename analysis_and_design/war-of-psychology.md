# 兵法心战系统(War of Psychology)

> 依据用户两板斧: "辅助分战略与战术两个层次; 战略是固定思路, 战术是实践方式";
> 每英雄: 技能组合 + 心理特点 + 三十六计系统化应用。

## 一、模型

```text
对位心理四层(见 playstyle-intel.md)
        │
        ▼
┌─────────────────────────────────────────────────────┐
│  战略(固定): Archetype → doctrine + 双主计           │
│  ─ 刺客 一击决胜     瞒天过海 / 擒贼擒王                │
│  ─ 法师 阵地控场     无中生有 / 隔岸观火                │
│  ─ 坦克 承伤为墙     李代桃僵 / 关门捉贼                │
│  ─ 射手 苟线为赢     假痴不癫 / 趁火打劫                │
│  ─ 辅助 让AD发光     欲擒故纵 / 顺手牵羊                │
│  ─ 战士 分带拉扯     围魏救赵 / 打草惊蛇                │
│  ─ 未知 静观为先     声东击西 / 以逸待劳                │
├─────────────────────────────────────────────────────┤
│  战术(压力档驱动):                                    │
│  ─ 劣势/大劣势: 走为上、假痴不癫                        │
│  ─ 均势:       打草惊蛇、声东击西                        │
│  ─ 优势:       趁火打劫、擒贼擒王                        │
│  ─ 未知:       假痴不癫、以逸待劳                        │
├─────────────────────────────────────────────────────┤
│  英雄级 override(TOML): 连招签名 / 心理特点 / 主计替换 │
│  当前内置 11 张英雄卡(亚索/劫/永恩/盲僧/薇恩/德莱厄斯/  │
│  阿狸/拉克丝/布里茨/雷恩加尔/卡特琳娜), 冷门英雄走分型   │
└─────────────────────────────────────────────────────┘
```

三十六计全表 36 条是唯一合法计名集; 覆盖卡里非法计名 → 丢弃 + 警告。
(这么做是因为计名是 UI 与 prompt 的共享语汇, 规范化先于丰富度。)

## 二、调用链(选人阶段自动调用)

```text
champ-select WS Update
  → compute_war_text(main.rs)
      → counter::pressure_of_matchup(压力档)
      → WarSystem::load().war_card(own, opp, pressure)
      → render_ui: (兵法 · 知之与用之, 多行正文)
  → RunesWindow: 深金心战卡(独立于心理图谱卡, 位于其下)
  → advisor: build_lineup_prompt / build_live_game_prompt 注入
      render_for_prompt 3-5 行紧凑版(战略两行 + 心理一句 + 战术一至两条)
```

## 三、与其他系统的关系

| 系统 | 心战提供 | 心战依赖 |
| --- | --- | --- |

| runes UI | 心战卡动显在选人窗 | — |
