# ChampR UI 设计规范

## 1. 设计原则

1. 状态只做“轻提示”，详细内容不抢占主界面。
2. 功能、状态、操作、详情四类元素职责分开。
3. 所有可点击目标高度至少 `32px`，避免误触。
4. 同一层级使用相同间距、圆角、字号和颜色。
5. 主窗口只保留决策信息，长文本进入详情区。

## 2. 颜色语义

| 状态 | 颜色 | 使用场景 |
| --- | --- | --- |
| 成功 / 正常 | `#22AA55` | LCU 已连接、Builds 成功、LoL 已启动、建议已生成 |
| 警告 | `#E6A817` | 正在处理、需要管理员授权 |
| 错误 | `#D64545` | 连接失败、功能失败、配置缺失 |
| 中性 | `#8A94A6` | 无状态、禁用、占位 |
| 卡片背景 | `#FFFFFF` | 功能区域 |
| 页面背景 | `#F5F7FA` | 主窗口背景 |

## 3. 字体层级

| 层级 | 字号 | 字重 | 用途 |
| --- | --- | --- | --- |
| 标题 | `22px` | 700 | 窗口标题 |
| 区块标题 | `15px` | 600 | 功能卡片标题 |
| 正文 | `14px` | 400 | 状态名、按钮 |
| 辅助文字 | `12px` | 400 | 详情、错误说明 |
| 小标签 | `11px` | 400 | 位置、版本号 |

## 4. 间距与尺寸

- 页面边距：`16px`
- 区块间距：`12px`
- 行内间距：`8px`
- 卡片圆角：`8px`
- 状态点：`8x8`
- 图标按钮：`28x28`
- 普通按钮高度：`36px`
- 主操作按钮：横向撑满或固定 `160px`

## 5. 主窗口推荐模板

```text
┌─────────────────────────────────┐
│ ChampR                          │
│ Builds, runes, all in one       │
├─────────────────────────────────┤
│ 功能状态                        │
│                                │
│ LCU      ●        [i]           │
│ Builds   ●        [i]           │
│ LoL      ●        [i]           │
│ Advice   ●        [i]           │
├─────────────────────────────────┤
│ 快捷操作                        │
│                                │
│ [ Apply Builds ]  [ Launch LoL ]│

├─────────────────────────────────┤
│ 详情                            │
│ (点击 i / ! 后显示)              │
└─────────────────────────────────┘
```

## 5.1 基本状态与快捷操作拆分

主窗口按职责分成三块：

### 状态区

只放“需要随时看到是否正常”的功能：

- LCU 连接
- LoL 运行状态
- Builds 应用状态
- Advice 生成状态

状态区只显示：

```text
功能名 + 状态点 + 详情图标
```

不放置任何操作按钮，避免误触。

### 快捷操作区

只放“用户随时会点击”的功能：

- 启动 LoL
- Apply Builds
- TTS Settings
- 复制当前建议
- 重播当前建议

统一按钮样式：

- 主操作：横向撑满或固定宽度
- 次操作：白底描边
- 图标可选 emoji

### 详情区

默认隐藏，点击状态区的 `ℹ️` / `❗` 后显示。

只放长文本：

- 错误原因
- DeepSeek 建议
- 成功/失败详情

## 5.2 推荐交互

- 状态区永不高亮成主操作
- 快捷操作区只做动作，不展示长文本
- 详情区可复制，可滚动
- 状态异常时状态点变红，并在详情区说明原因

## 6. 组件规范

### 状态行

- 左侧：功能名，固定宽度
- 中间：`8x8` 状态圆点
- 右侧：`28x28` 的 `i` 或 `!` 按钮
- 整行高度：`32px`

### 详情区

- 默认隐藏
- 点击状态行右侧图标后显示
- 使用只读 `TextEdit`
- 可复制

### 按钮

- 主操作：填充强调色
- 次操作：白底边框
- 图标按钮：`28x28`
- 所有按钮高度至少 `32px`

## 7. Slint 建议组件

优先使用：

- `VerticalBox`
- `HorizontalBox`
- `Rectangle`
- `Button`
- `TextEdit`
- `TouchArea`

避免在单个 `Text` 里拼接过多状态文本。

## 8. 验收标准

- 默认状态只显示绿点或红叹号
- 功能名和图标在同一行
- 详情点击后才出现
- 相同层级视觉尺寸一致
- 错误信息不直接暴露在主界面
